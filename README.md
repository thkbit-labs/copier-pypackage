# copier-pypackage

A modern Copier template for scaffolding Python packages and apps.

## 📁 Project Structure Overview

| File/Folder       | Purpose                                                                                                   |
| ----------------- | --------------------------------------------------------------------------------------------------------- |
| `.venv/`          | Virtual environment containing Python dependencies for the project                                        |
| `.vscode/`        | VS Code-specific settings and configuration (extensions, settings, etc.)                                  |
| `src/`            | Directory containing the main application source code                                                     |
| `tests/`          | Directory containing tests (unit tests, integration tests, etc.)                                          |
| `.env`            | Environment variables file (API keys, secrets, configs, etc.)                                             |
| `.env.test`       | Environment variables specific to the test environment                                                    |
| `.gitignore`      | Specifies which files/folders Git                                                                         |
| `.editorconfig`   | Standard configuration file used to set consistent source code formatting rules between different editors |
| `.python-version` | Specifies the Python version (used by tools like `pyenv`)                                                 |
| `justfile`        | Task automation file used by the `just` command runner                                                    |
| `LICENSE`         | The license for the project (e.g., MIT, Apache)                                                           |
| `main.py`         | The main Python entry point of the application                                                            |
| `pyproject.toml`  | Project configuration file (build system, linting tools like Ruff, etc.)                                  |
| `README.md`       | Project overview and instructions for installation and usage                                              |
| `ruff.toml`       | Configuration file for the Ruff linter (rules, formatting preferences)                                    |
| `uv.lock`         | Dependency lock file generated by [`uv`](https://github.com/astral-sh/uv)                                 |

## ⚙️ Development Setup

> **Required tools**
>
> -   **[uv](https://github.com/astral-sh/uv)** – Python dependency manager
> -   **[just](https://github.com/casey/just)** – Task runner
> -   **[watchexec](https://github.com/watchexec/watchexec)** – File‑watching test runner
> -   **[mise](https://github.com/jdx/mise)** – Toolchain / version manager

### 🐧 WSL / Linux

```bash
# 1 — Install mise
curl -sSfL https://github.com/jdx/mise/releases/download/v2025.1.6/install.sh | sh

# 2 — Enable mise in your shell
echo 'eval "$(~/.local/bin/mise activate bash)"' >> ~/.bashrc
source ~/.bashrc   # or restart terminal

# 3 — Install required CLI tools
mise use -g uv just watchexec
```

# 🔐 Setting Up SSH Key for GitHub

1. **Generate a new SSH key:**

    ```bash
    ssh-keygen -t ed25519 -C "youremail@example.com"
    ```

2. **Add your key to the SSH agent:**

    ```bash
    eval "$(ssh-agent -s)"
    ssh-add ~/.ssh/id_ed25519
    ```

3. **Copy your public SSH key:**

    ```bash
    cat ~/.ssh/id_ed25519.pub

    ```

4. **Add the key to your GitHub account:**

    - Go to GitHub → Settings → SSH and GPG keys
    - Click "New SSH key"
    - Paste your copied key and save

5. **Test your SSH connection:**

    ```bash
    ssh -T git@github.com
    ```
